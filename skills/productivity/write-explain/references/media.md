# 图解、网页与字幕视频

仅在已选用相应形式时读取和执行。制作形式服务于内容，不以工具能力决定题目范围。写作与解释均遵守主文件的“交付末尾的形式建议”：HTML 或视频未获用户明确选择时，先完成当前交付，有明显收益才在末尾建议并询问；用户已要求或同意的形式直接制作。

## 文字

适合短答案、概念定义、精确限定和叙事。复杂内容可采用一条贯穿的例子；无需为了视觉化而生成文件。

## 图解与图片

- 关系、流程、层次或比较适合图解。先确定图要回答的问题，再确定节点、连线、标签和图例。区分因果、顺序和关联。
- 简单工程图可用 Mermaid；要求独立成品或更复杂的可控标签时用 SVG。栅格插画的生成与编辑使用可用的 imagegen 工具或技能；不要把装饰图当成科学证据。
- 标签简短，解释放图注；重要含义不能只靠颜色区分。检查箭头方向、文本重叠、字号及图文一致性。
- 实际渲染并检查要交付的图。无法渲染时如实标明未验证，不把源码当作已检查图片。

## 交互 HTML

- 用交互表现一个有意义的变化，例如调参数看结果、切换方案作比较、逐步推进过程。静态主题不必强加控件。
- 优先制作可直接打开的自包含 HTML，内联必要 CSS、JavaScript 与 SVG。确有需要时才使用框架或远程依赖；遵守所在项目的已有技术选择。
- 标出输入、单位、默认值、模型假设和适用范围。提供重置或重播；动画支持暂停，照顾减少动态效果偏好。支持键盘操作和窄屏阅读。
- 打开页面，验证主要控件、默认值和边界值，检查错误、文字裁切及图形更新。模型推导或计算与展示结果必须一致。
- 提供可打开的成品链接，并在可用时用应用预览显示。未获发布授权时交付本地结果。

## 无配音字幕视频

- 默认不生成音频，不请求语音 API 密钥。字幕承担完整解释，配合必要的图形标签；用户要求视频时，默认包含字幕。
- 先确定一个学习目标与连续分镜，再把字幕拆到对应画面。未指定时按内容决定简短时长，不套用错误的“3 分钟到 1 分钟”解释：用户参考中的 `3b1b` 指 3Blue1Brown，借鉴数学可视化、连续变换和循序推导的表达思路。
- 先检查已有渲染和导出能力，再选择最少依赖的方案。可用已有动画库、程序绘图或浏览器录制等方式；仅在实际必要时调用对应技能。不默认安装重型工具或依赖付费服务。
- 字幕默认烧录进画面，以便无声观看；必要时附 SRT/VTT。控制每屏信息量、对比度与安全边距，停留时间足够阅读。字幕与动画状态一致，避免上一句未读完就跳到下一步。
- 交付实际可播放的视频文件。至少验证文件时长、画幅、起止画面、字幕显示和场景转折；能播放时检查完整播放，工具受限则说明尚未完成的验证。
- 导出失败时保留字幕、分镜和可运行的动画源文件，说明具体阻塞。HTML 动画可作为替代预览，但不能称为已经导出的视频。

## 组合交付

为每种形式分配任务，例如文章负责完整论证、图解释结构、交互展示参数影响。术语、符号、数据、颜色语义在各成品间保持一致。用户只要求一种形式时不附送整套媒体；只有组合确实有助于目标且符合请求范围时才组合。
