# Hallmark core rules

Use these as audit lenses, not universal style laws.

1. **Existing product wins.** Compare the surface with its design system,
   neighboring flows, content model, and interaction language.
2. **Content determines structure.** Flag a generic pattern when it weakens the
   task, not merely because it is common.
3. **Copy stays honest.** Treat unsupported metrics, testimonials, logos,
   screenshots, awards, and capabilities as trust risks.
4. **Tokens stay coherent.** Look for semantic reuse and intentional exceptions,
   not mechanical uniformity or a parallel token system.
5. **Assets stay real.** Distinguish owned product evidence from decorative fake
   chrome, dashboards, devices, and implied integrations.
6. **Interaction stays legible.** Inspect semantics, focus, targets, labels,
   state changes, reduced motion, and error recovery.
7. **Responsive means observed.** Source can suggest risk; rendered behavior is
   required to confirm overflow, wrapping, reading order, and visual hierarchy.
8. **Verification stays truthful.** Separate confirmed evidence, static signals,
   and checks that still require a browser or assistive technology.
